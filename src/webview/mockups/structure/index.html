How to read the snapshots

Stored Open means exactly open. Unfinished groups known nonclosed statuses: open, in progress, blocked and deferred. Unknown statuses are separate, not silently classified.

Unresolved direct blockers is a per-related-issue value, not the number of relationship links. A positive value means dependency blockage in this fictional model. Zero does not establish readiness. Unknown is not zero. Not-ready is a separate bd ready outcome, without a guessed cause.

Totals belong to each relationship, not a deduplicated count across Structure. Closed blockers count as resolved here only as a synthetic assumption; future CLI tests must verify semantics.

Reproducible browser checklist

Record browser name/version. Check each concept at desktop width in light, dark and simulated high contrast, at 360 CSS px, and at desktop width with 200% zoom; expand all groups and check a B preview at narrow width.

Check full IDs/titles, no overflow/clipping, readable status, visible focus, themed previews and reachable Close. Use Tab / Shift-Tab, disclosure Enter / Space and radio arrows; Enter on one B Unlink and Space on another. Sample Parent, open Blocked By, unknown-count Child and closed Blocked By previews; verify exact relationship, Escape/Close dismissal, visible focus returned to the invoking button and unchanged rows/counts. Closed-row buttons should be reachable only after expansion. Check A/C keyboard controls, with informational rows skipped. See README for details. Record results separately; this checklist is not a test result.
